# Alter Ego

WPF-приложение на .NET 8.

## Открытие
1. Откройте файл `AlterEgo.csproj` в VS Code.
2. Запускайте приложение из папки проекта.

## Текущая структура
- `App.xaml` — запуск приложения и ресурсы.
- `MainWindow.xaml` — главное окно выбора персонажа.
- `CharacterEditorWindow.xaml` — окно редактора/гардероба персонажа.
- `CharactersWindow.xaml` — окно «Мои персонажи».
- `Images/` — изображения персонажей.

Целевая платформа сохранена: `net8.0-windows`. Папки `obj/` и `bin/` не включены: это автоматически создаваемые файлы сборки.
